# 灯りの部屋 — 30秒リセット

疲れた人が、1日3回(朝・昼・夜)、30秒だけ立ち寄れる小さな部屋。
端末の日付・時刻と、鹿児島の実際の天気に合わせて、文章・背景・演出が自動で切り替わります。

最終目標:365日 × 朝昼夜 = 1095体験。毎月ぶんを足していきます。

---

## 全体の構造(2レイヤー)

```
┌──────────────────────────────────┐
│ レイヤーA:天気(背景＋雨・雪・雷)                      │ 自動制御
│   鹿児島の今の天気で背景を選び、雨/雪/雷を上に重ねる          │
├──────────────────────────────────┤
│ レイヤーB:30秒体験(演出テンプレ＋文章)                  │ データで指定
│   文章の出し方・間・締め方                            │
└──────────────────────────────────┘
```

天気は「演出」ではなく別レイヤー。どの演出を選んでも、その上に天気が独立して重なります。

---

## ファイル構成

```
reset30.html      … 本体(土台)。基本さわらない
templates.js      … 演出テンプレート集(12種)。演出を足すときだけ触る
content-data.js   … 日付ごとの文章・締め・演出指定。毎日の中身はここ
preview.html      … 背景が正しく置けたか一覧で確認するページ
bg/               … 背景画像(月×朝昼夜×晴曇)
  bg_09_morning.jpg          (9月 朝 晴れ)
  bg_09_afternoon.jpg        (9月 昼 晴れ)
  bg_09_night.jpg            (9月 夜 晴れ)
  bg_09_morning_cloudy.jpg   (9月 朝 曇り)
  bg_09_afternoon_cloudy.jpg (9月 昼 曇り)
  bg_09_night_cloudy.jpg     (9月 夜 曇り)
```

---

## 毎月の追加手順

### 1. 背景画像を用意(ちゃぴぴ)
月2種類 × 朝昼夜 = 6枚。晴れと曇りだけ。雨・雪・雷は曇り背景を流用します。

ファイル名の形:`bg_MM_zone.jpg` / `bg_MM_zone_cloudy.jpg`
- `MM` = 月(2桁。10月なら `10`)
- `zone` = `morning` / `afternoon` / `night`
- 例(10月):`bg_10_morning.jpg`, `bg_10_afternoon_cloudy.jpg` …

`bg/` フォルダに入れる。

### 2. 文章を書く(ゆわ&ちゃぴぴ)
その月の 30日 × 朝昼夜 = 90体験ぶんの「本文・締め・演出の意図」。

### 3. データ化(くろぴー)
文章を渡すと、`content-data.js` に追記した形で返します。

### 4. 確認
`preview.html` に月ぶんを追記して背景をチェック → `reset30.html` を開いて実機確認。

## content-data.js の書き方

日付キーは `"MM-DD"`(年は書かない=毎年使い回し)。

```js
"09-24": {
  morning: {
    template: "fadeLines",           // 演出(省略すると fadeLines)
    greeting: "あさ",                 // 上の小さな一言(任意)
    lines: ["本文1行目", "2行目"],     // 本文
    closing: "いってらっしゃい。",       // 締め(任意。無ければ演出だけで終わる)
    options: { lineInterval: 1400 }   // 微調整(任意)
  },
  afternoon: { ... },
  night: { ... }
}
```

### 表示の優先順位(フォールバック)
その日のデータが無くても空白になりません。
1. `SPECIAL_DAYS`(クリスマス等の特定日)
2. `DAY_CONTENT`(その日)
3. `MONTHLY_FALLBACK`(その月の汎用文)
4. `DEFAULT_FALLBACK`(共通の受け皿)

---

## 演出テンプレート(12種)

| 名前 | 演出 |
|---|---|
| `fadeLines` | 1行ずつ下から浮かぶ(基本) |
| `fadeAll` | 全文まとめて静かに現れる |
| `zoomLines` | 1行ずつズームしながら |
| `slideLines` | 1行ずつ左から流れ込む |
| `riseBlur` | ぼやけて→くっきり浮かぶ |
| `breathe` | 現れた文章がゆっくり呼吸する |
| `oneByOne` | 1行ずつ入れ替わりで見せる |
| `typewriter` | 1文字ずつ打ち込まれる |
| `centerHold` | 短い一言を中央に大きく置く |
| `quietText` | 最小限。静かに出して静かに終わる |
| `stillness` | 静寂。文字を消して間をつくる |
| `tapReveal` | タップで1行ずつ・光の粒が出る |

新しい演出は `templates.js` の末尾に足せます(書き方はファイル内コメント参照)。

---

## 天気の設定

`reset30.html` 内の `WEATHER` で調整:
- 場所(緯度・経度):初期値は鹿児島市
- 天気連動のオン/オフ

天気は [Open-Meteo](https://open-meteo.com/)(無料・登録不要)から取得しています。
